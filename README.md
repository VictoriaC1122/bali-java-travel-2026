# Bali x Java Travel Handbook

Static trilingual travel website for a June 2026 Indonesia itinerary.

## Languages

- Traditional Chinese
- English
- Indonesian

## Local preview

Open `index.html` directly in a browser, or run a simple static server:

```bash
python3 -m http.server 8080
```

- Official Indonesia eVisa portal: <https://evisa.imigrasi.go.id/>
- Official Bali levy portal: <https://lovebali.baliprov.go.id/>
